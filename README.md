# PaperLoop 下载

PaperLoop 是 Windows 桌面论文阅读器：导入英文 PDF，阅读中英对照内容，选择段落或图表向模型提问，记录批注，并运行有步数和证据检查的研究 Agent Loop。

点击 [最新版本的安装包](https://github.com/fuyoupeng2007/paperloop-download/releases/latest) 下载 `PaperLoop-Setup-0.3.0-win-x64.exe`。安装后填入自己的 DeepSeek API 密钥，点击“测试连接并保存”。安装包无需另装 Python、Node 或 Codex。

[▶ 观看 40 秒操作演示](https://github.com/fuyoupeng2007/paperloop-download/releases/download/v0.3.0/PaperLoop-0.3.0-Demo.mp4)。视频使用虚构论文与本地模拟模型；同一 Release 里提供示例 PDF，可下载后自己练习。

此仓库只放公开下载文件；用户论文、密钥和阅读数据不在安装包里。完整说明、目前的限制和常见问题见 [安装说明](INSTALL.md)。下载时可用同一 Release 中的 `SHA256SUMS.txt` 校验文件。
